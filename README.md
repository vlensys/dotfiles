# keybinds
```
# apps
SUPER + W - browser
SUPER + T - terminal
SUPER + Q - quit
SUPER + F/F11 - fullscreen
SUPER + V - toggle floating
SUPER + R - fuzzle!

# windows/workspaces
SUPER + X/RMB - rezise window
SUPER + Z/LMB - move window
SUPER + ARROW KEYS - change window focus
SUPER + 1-9 - toggle workspaces
SUPER SHIFT + 1-9 - throw window to x workspace
SUPER + M - music workspace
SUPER + S - special workspace
SUPER + D - communications workspace
SUPER SHIFT + M - throw window to music workspace
SUPER SHIFT + S - throw window to special workspace
SUPER SHIFT + D - throw window to communications workspace
```
